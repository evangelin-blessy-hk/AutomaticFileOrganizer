# Automatic File Organizer

## Description

A Python automation tool that organizes files into folders based on their file extensions.

## Features

- Organizes PDF files
- Organizes Images
- Organizes Audio files
- Organizes Videos
- Organizes Documents
- Organizes Compressed files
- Organizes Executables
- Organizes Excel files

## Technologies Used

- Python
- os module
- shutil module

## How to Run

1. Open `main.py`
2. Update the `SOURCE_FOLDER`
3. Run

```bash
python main.py

```
